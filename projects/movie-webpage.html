Movie webpage Project

Context

During unit one of SEP 10, we learned how to code basic HTML and CSS. We then used what we learned to create our "Movie webpage project". We were able to choose what we wanted our project to be about with the people we were assigned to work with and we chose the topic of a zombie apocalypse.

Content

In both movie trailers, The apocalypse and The apocalypse 2, we first had to make a plan on who did what to be organized and be persistent. We all came up with making our movie trailer on a zombie outbreak from a disease and survinging in it, The apocalypse, and trying to restore the world and humanity again one year after the apocalypse with mutated zombies and new characters better known as otjer survivors in The apocalypse 2. We used HTML to create the headings, paragraphs, divs, spans and more and we used CSS to add different colors other than just black and white as well as different fonts, borders, and much more.

Challenges

A few challenges i faced in this project were getting the images to have borders and having all p elements aligned in the center.

Take aways

A takeaway from this challenge or project would be to make sure you save the image you want to add to your code by saving the image and uploading the actual image onto the code and then writing the code for it to appear because without having the image added, the picture would not show.

Next steps

My next steps for this project would be to make it appear more eye catching for others looking at it to be more interested and add more features to both the movie trailer and sequence to make it be and look more detailed and eyecatching.
